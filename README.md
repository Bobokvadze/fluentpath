# FluentPath — ინგლისური ენის სასწავლო პლატფორმა (ქართული ინტერფეისით)

100% უფასო, ულიმიტო, ოფლაინ რეჟიმში მომუშავე ინგლისური ენის სასწავლო ვებ-აპლიკაცია (სასწავლო გეგმა A1–C1, დამატებითი მასალა C2).

## მოდულები

სასწავლო გეგმა (25 ერთეული, შემაჯამებელი ტესტები) · ლექსიკონი (979 შერჩეული სიტყვა/ფრაზა, IPA) · გრამატიკა · კითხვა · მოსმენა · საუბარი (ფრაზები და დიალოგები მეტყველების ამოცნობით) · წერა · ბარათები (ინტერვალური გამეორება) · ტესტები (დონის განსაზღვრა) · პროგრესი (სუსტი მხარეების ანალიზი).

## ტექნოლოგიები

- სუფთა HTML/CSS/JavaScript, build-ის გარეშე. PWA (Service Worker → ოფლაინ რეჟიმი).
- პროგრესი ინახება ბრაუზერში (localStorage); სურვილისამებრ — Supabase ანგარიშით სინქრონიზაცია.
- ყველა გამოყენებული სერვისი უფასოა: Supabase (Free plan), Google Fonts, dictionaryapi.dev, ბრაუზერის ჩაშენებული ხმის სინთეზი და მეტყველების ამოცნობა.

## ლოკალურად გაშვება

```bash
python -m http.server 8765
```

შემდეგ გახსენით http://localhost:8765

## ტესტები

საჭიროა მხოლოდ Node.js 20+ (დამატებითი პაკეტები არ არის).

```bash
npm test
```

GitHub-ზე ტესტები ავტომატურად ეშვება ყოველ push-ზე (`.github/workflows/test.yml`).

## Supabase-ის უსაფრთხოება (ერთჯერადი ნაბიჯი)

გახსენით Supabase Dashboard → SQL Editor და გაუშვით [`supabase/rls.sql`](supabase/rls.sql).
ის ჩართავს Row Level Security-ს, რომ თითოეულმა მომხმარებელმა მხოლოდ საკუთარი პროგრესი ნახოს და შეცვალოს.

## სასარგებლო შენიშვნები დეველოპერისთვის

- ფაილებს content-hash არ აქვთ: `sw.js`-ში ფაილების სიის შეცვლისას გაზარდეთ `CACHE_NAME`.
- `index.html`-ის inline სკრიპტის შეცვლისას განაახლეთ მისი `sha256` ჰეში Content-Security-Policy-ში (`npm test` შეგახსენებთ).
- აპის PNG ხატულები: `node scripts/generate-icons.js`.

## სასწავლო მასალის სტრუქტურა

- სასწავლო მასალა ინგლისურადაა (`js/content/`), თარგმანები ცალკეა: `js/content/i18n-ka.js` (`App.tr(section, id, field)`).
- სასწავლო გეგმა: `js/content/curriculum.js` (დონეები → ერთეულები → გაკვეთილები), ლოგიკა: `js/curriculum-engine.js`.
- ლექსიკის, გრამატიკის, კითხვის, მოსმენის ან წერის შეცვლის შემდეგ: `node scripts/build-content-index.js` (`npm test` შეგახსენებთ).
- ლექსიკის შემოწმება: `node scripts/validate-vocab.js`.

### თარგმანების დამატება

```bash
node scripts/export-translations.js > to-translate.json
```

შეავსეთ თითოეული ელემენტის `ka` ველი (ადამიანმა ან უფასო AI ინსტრუმენტმა, მაგ. Gemini; `context` ველი მნიშვნელობის გარკვევაში ეხმარება), შემდეგ:

```bash
node scripts/import-translations.js to-translate.json
```

იმპორტი უარყოფს უცნობ გასაღებებს, შეცვლილ ინგლისურ წყაროს, ცარიელ, ინგლისურის იდენტურ ან არაქართულ მნიშვნელობებს (`--dry-run` — მხოლოდ შემოწმება).
